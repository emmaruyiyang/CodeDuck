It perches on top of your VS Code window and keeps an eye on Claude Code: walks while Claude works, poops 💩 when it's waiting on you, and blows it all up 💥 the moment you reply.

Install

  1. Open the .dmg and drag QuackCode into Applications
  2. If macOS blocks it on first launch: System Settings → Privacy & Security → scroll down to QuackCode and click “Open Anyway”.
    If it says the app is “damaged”, run xattr -cr /Applications/QuackCode.app in Terminal
  3. System Settings → Privacy & Security → Accessibility, turn on QuackCode, then quit from the 🦆 menu bar icon and reopen
  4. Open VS Code and use Claude Code as usual — the duck shows up on its own
