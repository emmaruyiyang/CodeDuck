三步装好

下载后大约 1 分钟即可开始

下载并拖入

打开 .dmg，把 QuackCode 拖进「应用程序」

右键打开

首次在「应用程序」里 右键 → 打开 放行（未签名）

授权辅助功能

系统设置 → 隐私与安全性 → 辅助功能，打开 QuackCode

开始使用

打开 VS Code 用 Claude Code，鸭子自动出现在窗口上沿

⚠️ 关于"未签名"提示：当前版本未做 Apple 代码签名，首次打开需 右键 → 打开。 若提示"已损坏 / 无法验证开发者"，在「终端」运行 xattr -cr /Applications/QuackCode.app 后再打开即可。 需要授予「辅助功能」权限，鸭子才能跟随 VS Code 窗口。
